# Citation Downloads — fetch checklist

Companion to [`wiki/98_provenance_and_citations.md`](../wiki/98_provenance_and_citations.md).
Cody fetches these. Save each into `references/<subdir>/` with the filename in
the last column. `[OA]` = open access / free legally; `[PW]` = paywalled
(preprint or library copy usually available); `[HIST]` = historical, scan
usually on archive.org / Gallica / GDZ / Internet Archive.

**Identifier confidence:** IDs given below are from memory. Ones marked `?` need
a 10-second check before you rely on them; the author+year+title is always
enough to find the item.

A bundled `references/papers.zip` is optional — the wiki cites by key, not by
file, so nothing breaks without it.
