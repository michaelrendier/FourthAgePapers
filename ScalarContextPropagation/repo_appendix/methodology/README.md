# methodology — the process, not the results

Copied from `~/.claude/skills/`, 2026-09-21. Kept for anyone
reproducing *how* this paper was built, not what it found.

- **`observer-position_SKILL.md`** — built specifically from two real
  mistakes in this paper's own §9.3 working sessions (a Native-Space
  object analysed in Cartesian coordinates; a continuous generator
  quantized onto a 16-point lattice without noticing). States a
  coordinate frame and an aperture before trusting a hyperdimensional
  result, the same discipline a camera pose or viewport offset already
  gets in lower-dimensional work.
- **`cs-paper-code-conventions_SKILL.md`** — the three real
  code-in-a-CS-paper conventions (scikit-learn/no-code,
  Annotated-Transformer/literate, pseudocode+checklist) this paper
  itself is written in, decided per-component rather than uniformly.
